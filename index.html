AgroSentinel ●

Sistema de decisión agrícola en tiempo real

Python FastAPI PostgreSQL Docker FIWARE Orion IoT / ESP32 FAO-56
Problema

Los datos de sensores de campo son ruidosos e inconsistentes. Los sistemas tradicionales fallan o dan falsas alarmas cuando los datos no son perfectos.

Solución

Pipeline en tiempo real: sensor → FastAPI → FIWARE Orion → decisión. Calcula VPD (FAO-56), ETc y riesgo fitosanitario. Integrado con datos reales del portal UCO/CitriData (finca La Oliverica, TEF). El sistema mantiene decisiones válidas incluso con entradas ruidosas o incompletas.

Impacto

Alertas basadas en VPD para detección temprana de enfermedades · recomendaciones agronómicas basadas en sensores y datos climáticos · detección automática de fallos de hardware
